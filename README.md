# Khairul Azmi - Personal Blog

Welcome to my personal blog! This is a showcase of my interests in web development and technology.

## 📋 Project Description

This is a fully responsive personal blog website built with HTML, CSS, and JavaScript. The blog features multiple pages where I share insights, tutorials, and thoughts about web development and software engineering.

## ✨ Features

- **Responsive Design** - Works seamlessly on desktop, tablet, and mobile devices
- **Dark Mode** - Toggle between light and dark themes with persistent storage
- **Mobile Navigation** - Hamburger menu for mobile-friendly navigation
- **Interactive Elements** - Smooth animations and transitions
- **Multiple Pages** - Home, About, Blog, and Contact sections
- **Contact Form** - Get in touch with built-in contact form validation
- **Blog Posts** - Multiple sample posts with professional styling
- **Professional Layout** - Clean and modern design with smooth user experience

## 🛠️ Technologies Used

- **HTML5** - Semantic markup and structure
- **CSS3** - Modern styling with flexbox and grid layouts
- **JavaScript** - Interactive features and form validation
- **Git & GitHub** - Version control

## 🎨 Features Overview

### Responsive Design
The website is fully responsive and adapts to different screen sizes:
- Mobile devices (320px and above)
- Tablets (768px and above)
- Desktop (1024px and above)

### Dark Mode
Toggle between light and dark themes. Your preference is saved in local storage.

### Interactive Elements
- Smooth animations on page load
- Hover effects on buttons and cards
- Mobile menu with hamburger navigation
- Form validation on contact page

## 🚀 How to Use

1. Clone this repository
   ```bash
   git clone https://github.com/Imzaa/personal-blog.git
   ```

2. Navigate to the project directory
   ```bash
   cd personal-blog
   ```

3. Open `index.html` in your web browser or use a local server
   ```bash
   # Using Python 3
   python -m http.server 8000
   
   # Using Node.js
   npx http-server
   ```

4. Visit `http://localhost:8000` in your browser
